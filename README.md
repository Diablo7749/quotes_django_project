# Quotes Django Project

Web application for managing quotes, authors and tags built with Django.

## Features

- User registration and authentication
- Add and manage quotes
- Add and manage authors
- Tag system for quotes
- Search quotes by tags
- Pagination support
- Top 10 tags
- MongoDB data migration
- Scraping quotes directly from website

## Technologies

- Python
- Django
- PostgreSQL
- MongoDB
- BeautifulSoup
- HTML
- CSS
- Bootstrap
